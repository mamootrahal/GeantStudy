# GeantStudy

Изучение Geant4 и нужного для него C++.

## Структура
- `lessons/cpp/` — уроки по C++ (C1–C7)
- `lessons/geant4/` — уроки по Geant4
- `exercises/` — мой код к заданиям
- `answers/` — мои ответы на вопросы «Проверь себя»

## Как работаем
1. Пишу код/ответы в VS Code на любом устройстве.
2. `git add . && git commit -m "..." && git push`
3. Claude делает `git pull` и проверяет.

- [x] G1. Архитектура Geant4: Run → Event → Track → Step
